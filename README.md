# Bybit Screener

Скрининг монет Bybit по волатильности и тренду, торговые планы с уровнями входа/стопа/тейков и бумажный
портфель с лесенкой — всё в браузере, без своего сервера.

> ⚠️ Это инструмент для анализа и торговли на свой страх и риск. Никаких гарантий доходности.

## Недоступно в этом регионе

Три функции **отключены в интерфейсе** (страницы открываются с объяснением, ссылки из шапки и кабинета убраны):

| Маршрут | Что отключено | Почему |
|---|---|---|
| `/api` | подключение ключей Bybit | ключи тестнета в этом регионе не выдаются |
| `/live` | реальная торговля ордерами | тестнет недоступен для проверки, мейннет не подтверждён реальной сделкой |
| `/bot` | локальный Telegram-бот (Go) | бот не работает: Telegram- и Bybit-эндпоинты недоступны, починить и проверить здесь нельзя |

Код (`src/api/privateApi.ts`, `src/api/live.ts`, `src/pages/{ApiPage,LivePage,BotPage}.tsx`, каталог `bot/`) остался
в репозитории: заглушка — `src/components/BlockedFeature.tsx`, вернуть функции в роуты достаточно снять блокировку.
Работают и полностью доступны: скринер, торговые планы, бумажный портфель и разбор сделок.

## Возможности

- **Скринер**: до 200 монет, ранжирование по «Приоритету» — «куда действительно стоит входить» (уверенность +
  чистота/сила тренда + участие объёма − штрафы за перегрев RSI, растянутую серию и шорты). Быстрый «Вход»
  прямо из таблицы. Знак «?» в шапке откроет подробный walkthrough-обзор всех инструментов (можно пропустить
  и вернуться позже).
- **Торговый план по символу**: EMA20/50, ATR(14), Donchian-20, RSI, наклон/R² → направление, зона входа,
  стоп 1,8×ATR, цели 1R/2R/3R, расклады по всем таймфреймам, график стратегии (чистый SVG).
- **Фильтры качества**: сетап только при R² ≥ 0.5, объём ≥ 0.9 среднего и ATR% ≤ 7; шортам — более высокая планка.
- **Бумажный портфель**: позиции в localStorage, выход лесенкой TP1 70% / TP2 20% / раннер 10% до TP3,
  перенос стопа в безубыток после TP1, честный учёт ликвидации, комиссий и маржи. Кнопка «Закрыть по рынку»
  в таблице.
- **Портфельный лимит**: задействованный капитал (сумма марж открытых позиций) не может превышать депозит.
- **Реальная торговля** — отключена в этом регионе (см. раздел выше), код движка оставлен в репозитории.
- **Защита от «margin call раньше стопа»**: вход блокируется, если при выбранном плече ликвидация ближе
  стопа (стоп занимает ≤70% пути до ликвидации).

## Как работает стратегия

План строится в браузере по 200 свечам (минимум 55):

- направление: цена относительно EMA20/EMA50 + наклон и чистота тренда (R²), RSI, импульс, объём;
- вход — лимитная заявка по середине зоны между ценой и EMA20 (покупка отката), стоп 1,8×ATR от нижней
  границы зоны, цели 1R/2R/3R;
- уверенность (8..96) — непрерывная оценка качества сетапа;
- качественные фильтры отсекают шум: слабый тренд, мёртвый объём, ураганную волатильность;
- кнопка «Вход» в скринере открывает бумажную позицию мгновенно (размер из риска, плечо и ставка — из общих
  настроек сессии).

Бумажный выход — лесенка: TP1 фиксирует 70% позиции, TP2 — ещё 20%, раннер 10% едет до TP3; после TP1 стоп
переносится в безубыток. Стоп, безубыток и TP3 закрывают остаток. Открытые позиции переоцениваются по живым
ценам, комиссия учитывается за круг.

## Реальная торговля (отключена)

> Страницы `/api` и `/live` в этом регионе заблокированы: тестнет недоступен для проверки, а мейннет не
> подтверждён реальной сделкой. Ниже — описание механики, которую вернёт в роуты снятие блокировки.

1. Создай API-ключи (для отладки — на **testnet.bybit.com**).
2. Вставь их на странице `/api` (сеть **Тестнет**) → «Сохранить и проверить».
3. На `/live` введи символ и таймфрейм — живой план → «Открыть ордер (тестнет)».

Что делает движок (всё по плану, как в бумажном режиме):

- устанавливает плечо;
- ставит лимитный вход по середине зоны со стопом (триггер — MarkPrice);
- вешает лесенку: reduce-only лимитки TP1/TP2/TP3;
- по кнопке закрывает по рынку и переносит стоп в безубыток.

Подпись запросов — HMAC-SHA256 прямо в браузере (CORS Bybit это разрешает), сервер не нужен. Движок живёт,
пока вкладка `/live` открыта.

### Безопасность

- Секрет API хранится только в localStorage браузера — никогда не выкладывай его в код/репозиторий.
- Для **мейннета** используй ключ **без права вывода** и с ограничением по IP; торгуй только после отладки
  на тестнете. Мейннет-действия требуют явного подтверждения в интерфейсе.
- GitHub Pages — статический хостинг: скрипты видны всем, но ключ остаётся в твоём браузере.

## Telegram-бот (локальный, на Go) — отключено

> Страница `/bot` заблокирована в этом регионе: бот не работает (Telegram- и Bybit-эндпоинты недоступны), проверить
> и починить его здесь нельзя. Код в `bot/` оставлен как есть — вернётся в роуты вместе со снятием блокировки.

Браузер не может сам поллить Telegram (CORS заблокирован), поэтому бот — это **отдельный бинарник** (win/linux),
который ты запускаешь на своей машине рядом с этим приложением:

- **без ключей Bybit** (`mode: "paper"`, по умолчанию): бумажный портфель в `paper.json`, торговля кнопками
  прямо из Telegram — «Сделка» (кандидаты → риск → плечо → подтверждение), «Позиции» (безубыток/закрыть),
  «Отчёт» по запросу, «Стоп всего»;
- **события по смолу**: TP1/TP2/TP3, стоп, перенос в безубыток и **ликвидация по марже** приходят в чат сразу
  после тика цен (источник — публичные тикеры/свечи Bybit, приватный API не нужен);
- автоторговля = тот же движок стратегии (порт на Go): топ-N по обороту → план → вход+стоп+лесенка;
- **связка с браузером**: бот поднимает локальный API `127.0.0.1:8787` (CORS); страница `/bot` шлёт туда конфиг
  и показывает снимок бумажного портфеля (`/paper`); там же — инструкция и **скачивание бинарников**
  (собираются в CI в `public/bot/`).
- `mode: "live"` — реальные ордера через API Bybit (нужны ключи); всё на изолированной марже, лимит средств —
  максимальная сумма маржи, которую может занять торговля.

Сборка из исходников: `cd bot && make build` (linux/amd64, linux/arm64, windows/amd64). Тесты: `go test ./...` (запускаются и в CI).

## Разработка

- Стек: Bun, Vite, React 19, TypeScript (strict), React Router (HashRouter), TanStack React Query; бот — Go (stdlib).
- Стили — `src/index.css`; график — чистый SVG; UI на русском, термины с тултипами.
- Тесты: `tests/` (метрики, план, скринер, бумажные позиции, приватный API, реальный движок) + `bot/` (Go).
